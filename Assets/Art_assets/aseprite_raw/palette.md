# Palette (mandatory)

Only the 52 colours below may be used in any `.aseprite` file in this folder. Any other colour counts as a bug.

- Do not add colours to the palette, and do not use colours outside it.
- Every pixel must be fully opaque or fully transparent. No semi-transparent pixels, and no anti-aliasing to colours that are not in the palette.
- If a colour you need is missing, ask about extending the palette instead of approximating with an off-palette colour.
